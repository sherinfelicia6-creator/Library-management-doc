# BIBLIOTHECA

 ## SMART LIBRARY MANAGEMENT SYSTEM

 ## INTRODUCTION

   Bibliotheca is a smart and customizable library management platform which helps different types of libraries manage books,borrowing,returns and other library services efficiently.

## OBJECTIVES

- To provide a common platform form differnt types of libraries for both librarian 
   and userTo create a simple and user-friendly online library management system.

- To help users easily search, view, borrow, and return books.

- To help the library owner manage books and user records efficiently.

- To provide real-time book availability information.

- To  make library management faster and organized.

## FEATURES

### USERS:

1.Librarian

2.Reader

### LIBRARIAN:

 **Library type:** (College/School/Private/Government)

 **Library Details:** Add the library name and location
 
 **Book categories:** Manage different book categories
 
 **Blocks or sections:** To Organize the books.
 
 **Book availability:** Ensure the availability status of the book.
 
 **Reader management:** Manage the registered library users record.
 
 **Add Remove Update:** To add,remove or update a book. 

### LIBRARY USER:


**Search Book:** Search box for users to search what book they need.

**Select book category:** Allows user to browse different categories.

**Book availability:** Allows user to view the availability of the book.

**Location of books:** Helps user to find the book easier.

**Borrow and confirm borrowing:** To confirm the book to be borrowed.

**Return Date:** To ensure the book is returned at the correct time to avoid extra charge.

**Purchase books:** To purchase the book if online purchase is available

## INSTALLATION

- Download and install Visual Studio Code.

- Create a new folder named library management system.

- Open the folder in Visual Studio Code.

- Create the required files.

- index.html

- style.css

- script.js

- Add the Bibliotheca website code to the respective files.

- Save all the files.

- Open index.html in a web browser to run the website.

## USAGE

### LIBRARIAN

- Open the Bibliotheca website.

- Log in as a librarian.

- Enter the library details such as library type, name, and location.

- Add and manage book categories.

- Organize books into blocks or sections.

- Add, remove, or update book details.

- Check and update book availability.

- Manage registered reader records.

### READER

- Open the Bibliotheca website.

- Log in as a reader.

- Search for the required book.

- Browse books by category.

- Check the availability of the book.

- Find the location of the book.

- Borrow the book and confirm the borrowing.

- Check the return date.

- Purchase the book when online purchasing is available.
